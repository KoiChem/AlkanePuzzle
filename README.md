# アルカンパズル

「並べる」と「名付ける」でアルカン・シクロアルカン・アルコールの構造と命名を学習します。

## 共通設定の管理

`admin.html` にアクセスし、管理パスワードで設定画面を開きます。URLの `?admin=1` では設定を開けません。

難易度設定と管理パスワードの照合用ハッシュは `data/shared-settings.json` が正本です。編集は下書きとなり、「GitHubへ保存」でリポジトリの `main` に保存します。保存時に、対象を `KoiChem/AlkanePuzzle` に限定した fine-grained personal access token（Contents: Read and write）を入力してください。トークンは端末や公開ファイルには保存しません。

パスワード変更では、現在のパスワード、新しいパスワード、確認用入力を使います。変更を下書きに反映した後、GitHubへの保存で確定します。照合用ハッシュは公開JSONに含まれるため、画面の認証は簡易ロックです。実際の書き込み権限はGitHubトークンが担います。

GitHub保存とPages公開への反映は別です。管理画面は保存後に公開JSONを確認し、同じ内容が配信されるまで「公開への反映待ち」と表示します。確認が終了した場合は「公開反映を確認」で再試行できます。各端末は起動・再読み込み時に共通設定を取得します。進行中の問題は変更されません。取得に失敗した場合は学習を開始せず、再試行を案内します。

以前のブラウザ内の難易度設定は適用しません。音の設定は引き続き端末ごとに保持します。学習画面のOHボタンによる切り替えは、その起動中だけの操作です。共通のアルコール出題設定は管理画面で保存します。

他の管理者が先に更新した場合は、元のファイルSHAとの不一致により保存を拒否します。下書きを「コードとして書き出す」で保全し、ページを読み直して最新の共通設定に変更を反映してください。

## シクロの置換基数

「名付ける」の設定に「シクロの置換基を1個までにする」があります。初期値はすいすいのみONです。ONでは、シクロの置換基とOHを合計0〜1個に制限します。「環に置換基を必ず付ける」もONの場合は1個のみになります。通常の置換基数・種類数の下限よりこの制限を優先します。OFFでは通常の設定に戻り、鎖状分子と「並べる」の条件は変わりません。

## 検証

Node.js、Playwright、Google Chromeを利用して `node --test tests/*.test.cjs` を実行します。ブラウザテストは公開GitHubへの書き込みを行わず、外部API応答だけをテスト用に置き換えます。

共通設定、認証・パスワード変更・保存競合、シクロの個数、旧ローカル設定の無視、取得失敗時の動作、既存のパネル操作・解答保持を検証します。
