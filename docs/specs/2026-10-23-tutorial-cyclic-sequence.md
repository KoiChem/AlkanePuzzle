## 座標と経路

座標は1始まりの `(行,列)`。

シクロオクタン:

`(1,3) → (1,4) → (1,5) → (2,5) → (3,5) → (3,4) → (3,3) → (2,3) → (1,3)`

ジメチルシクロヘキサンの案内経路:

`(1,3) → (2,3) → (2,4) → (2,5) → (3,5) → (3,4) → (3,3) → (2,3) → (2,4) → (2,5) → (1,5)`

環の一部をなぞり直す。同じ結合を重複させず、通過した結合を集約する。逆向きや別の連続経路でも、空の盤面から1回のドラッグで正しい固定構造を作れば達成する。複数回の描画や、組み立て済み構造のなぞり直しだけでは達成しない。

第10課題で追加する枝は `(2,4)→(1,4)`、`(3,5)→(4,5)`、`(3,4)→(4,4)`、`(3,3)→(4,3)` の4本。既存の2本を描き直させない。

## 光の案内

第9課題では経路の重複位置を省かず、320msごとに1マス進む。最初は1、2、3マスと累積点灯し、4マス目からは直近3マスだけを点灯する。

- ① → ①② → ①②③ → ②③④ → ③④⑤ → …
- 同じ炭素への再訪も、その出現順で再点灯する。
- 最後の状態を500ms保持し、400ms消灯してから繰り返す。
- 操作中・非表示中の時計停止、reduced-motionでも必要な案内を表示する既存方針を維持する。
- 第8課題は既存の環の案内を8炭素へ適用し、4マス目で始点を消し、閉環時に再点灯する。

## 取り消しと検証

Undoは盤面と一筆書き達成を同時に戻す。やり直すと段階開始時の構造とクリア待ちへ戻す。キャンセル操作は確定しない。段階移行時は履歴と達成を分離する。

単体テストで構造名、分割描画の拒否、逆向き、Undo、4本の枝への継承、各時刻の点灯を確認する。ブラウザでは全12課題の実操作、経路上の再点灯、タッチ入力、クリア・キャンセル、狭い画面の収まりとボタン間隔を確認する。実機Safariの確認とは区別する。
