# チュートリアル4段固定・自動進行

ユーザー承認: 2026-10-23。第8課題完成後はクリアし、空の盤面からジメチル体を一筆で描く。

- 全課題で7列×4段を表示。前半7課題を維持し、後半はシクロオクタン→1,5-ジメチルシクロオクタン→1,3,5,7-テトラメチルシクロオクタン→1,3,5,7-テトラブロモシクロオクタン。全11課題。
- 完成後、指を離し入力確定してから1500msで次へ自動移行。次へは完成後にだけ表示する待ち時間短縮用の補助ボタン。毎回押す必要はない。
- クリアは本人が操作。第2・3・8・9課題にクリア待ちを設ける。第9課題のクリア前はシクロオクタンを表示し、クリア後に空の盤面で一筆描画を待つ。
- 未完成・入力中・非表示時は自動移行を取り消す。Undo・やり直すで前の自動移行予約を残さない。再び完成したら1500msを取り直す。最終課題では自動移行しない。
- 環は (2,3)→(2,4)→(2,5)→(3,5)→(4,5)→(4,4)→(4,3)→(3,3)→(2,3)。座標は1始まり。
- 一筆経路は (4,6)→(4,5)→(4,4)→(4,3)→(3,3)→(2,3)→(2,4)→(2,5)→(3,5)→(4,5)→(4,4)→(4,3)→(3,3)→(2,3)→(1,3)。逆向きも許容。空から一筆で完成させた証拠が必要。
- 第10課題で (2,5)→(2,6)、(4,3)→(4,2) の2本を追加。第11課題で枝先 (1,3),(2,6),(4,6),(4,2) をBrへ上書き。タップ配置も許可。
- 直近3マスの点灯、動きを減らす設定でも必要な案内と静かな星、効果音、左端スワイプ抑制を維持。ボタンの間隔を維持。320×568からレイアウトを確認する。

検討した進行: 毎回手動の次へは操作数が多いため採用しない。完成時に即切替・自動消去は完成を見る時間とクリア練習を損なうため採用しない。1500ms表示後の自動進行＋手動クリアを採用。
