# レモン色・点灯を残すスワイプ案内

基準: 87d0a9a。ユーザー承認: レモンイエロー、順に点灯して通過済みを保持、押すボタンは明確な点滅、実装・公開。

1. 実際の点灯順序・累積・消灯・繰り返し・操作中停止をブラウザテストで確認する。
2. 共有タイムラインでマスの点灯を同期し、開始印を削除。黄色1秒／通常色1秒のボタン点滅を実装する。
3. 通し操作、環の経路順、スマホ表示、WebKit、タッチ、音声、動きを減らす設定を確認。
4. レビュー・適切な回帰テスト後、対象ファイルだけ公開し、配信内容と公開操作を確認。

開始前: 従来表示では新しいブラウザテストが「three-cell swipe animation absent」で失敗することを確認。
判断: 操作中は進行中の点灯をその場で停止し、未完了なら指を離した後に再開する。ページ非表示・フォーカス離脱中も停止する。環の最後の重複した開始マスは再消灯せず、全体の点灯を保持する。
既存のtransient.html削除、.playwright-mcp/output/tmpは変更に含めない。


## 検証結果

- 最終コードで全225回帰テスト成功。
- Chromium/Playwright MCPとWebKit CLIで順次点灯、通過済みの保持、全点灯後の消灯と繰り返しを確認。1/2/3マス点灯の画面を目視確認。
- 「始」の文字・丸印なし。環は経路順に点灯し、再描画で周期がリセットされない。
- 操作中停止、ボタンの黄色／通常色の2秒周期、動きを減らす設定、blur/focus復帰を確認。
- レビューで指摘されたvisibility-only復帰を再現するテストの失敗を確認し、visible時の再描画を追加して成功。
- 全11課題、スマホ320×568/390×664/430×740、768/1280px幅、Undo・キャンセル・長押し・Iドラッグ・音声を確認。
