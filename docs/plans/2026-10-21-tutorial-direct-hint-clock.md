# 必須ガイドの直接切替と淡い黄色

基準: 66045ff。承認: 推奨方針で実装・検証・公開。

調査: 通常設定では動くが、prefers-reduced-motionをreduceにするとコードが案内を完全停止する。ユーザー端末の設定は不明。公開資産は基準コミットと一致していた。検証用の直接色切替はChromium/WebKitで抑制設定下でも動作。

1. 両設定で動くことを確認するブラウザテストを先に変更し、旧実装で失敗することを確認。
2. 一つの時計で経路とボタンを更新し、淡い黄色#FFF9B0へ変更。必須ガイドと装飾の抑制を分ける。
3. CSS/WAAPIなし、表示中blur、非表示復帰、再描画、入力中停止を確認。
4. Chromium/WebKitで全11課題・スマホ表示・タッチ・音声・Undoを検証。適切な回帰テストとレビューを行う。
5. 対象だけコミットし、公開資産の一致と公開ページの動作を確認。

実装判断: タイマーは次の色変化の時刻だけを予約し、経過時間から現在の状態を求める。操作中・非表示中は予約を止める。paintは色クラスだけを更新し、進行や案内文を毎回再描画しない。表示中のblurでは操作をキャンセルし、案内時計の停止条件にはしない。
既存のtransient.html削除と.playwright-mcp/output/tmpは変更に含めない。
